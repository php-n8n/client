# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of the library.

| Version | Supported |
| ------- | --------- |
| v1.0.3  | ✅        |
| v1.0.2  | ❌        |
| v1.0.1  | ❌        |
| v1.0.0  | ❌        |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately and do not disclose it publicly until it has been reviewed.

### How to Report

Send an email to:

**[contact@php-n8n.com](mailto:contact@php-n8n.com)**

Please include:

* A description of the vulnerability
* Steps to reproduce the issue
* The affected version(s)
* Any proof-of-concept code or screenshots, if applicable

### What to Expect

* You will receive an acknowledgement within 7 days.
* Valid security issues will be investigated and addressed as soon as possible.
* If the report is accepted, a fix will be developed and released before public disclosure whenever possible.
* If the report is determined not to be a security vulnerability, an explanation will be provided.

Thank you for helping keep php-n8n secure.
